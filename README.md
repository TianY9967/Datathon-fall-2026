# Datathon-fall-2026
For datathon fall 2026 submission
This website app is basically for safety managers and relative professionals.
When a safety manager in an company is reviewing safety risks, the manager would like to quickly identify frequent incident pattern and severe outcomes associated with them.
So that the manager can prioritize prevention effort and safety resources before the injuries occur, and leverage limited budget for people who need it at once.
It asks for 'sector, event type, source(hazard), place' as input, and tells user historical frequency of an event, priority of the event and proportions.
